# Cloud-Based-Data-Processing-Pipeline-with-AWS-and-PySpark
Designed and implemented an end-to-end data processing pipeline on AWS cloud infrastructure to analyze a large-scale dataset from Kaggle. The project focused on leveraging serverless AWS services to perform efficient data manipulation and transformation.

# Key Responsibilities & Achievements:
• Architected a scalable cloud solution using AWS S3 for data storage, AWS Glue for serverless data processing, and IAM for secure access management
• Developed PySpark scripts within AWS Glue Notebook to perform complex data transformations and cleaning operations on large datasets
• Implemented proper data partitioning and optimization techniques to enhance query performance and reduce processing costs
• Established secure IAM roles and policies to ensure least-privilege access to AWS resources
• Successfully processed and prepared data for downstream analytics and machine learning applications

# Technologies Used:
AWS S3, AWS Glue, AWS IAM, PySpark, Python, Kaggle Datasets
